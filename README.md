# سامانه ممیزی سالیانه پتروشیمی‌های عسلویه

سامانه ثبت نمرات، رتبه‌بندی، داشبورد و گزارش PDF برای ممیزی شرکت‌های پتروشیمی در پنج بخش:
محیط زیست، بهداشت، ایمنی، مدیریت بحران و آتش‌نشانی.

- بخش **محیط زیست** کامل است (۳۵ بند، داده ممیزی ۱۴۰۴ برای ۱۲ شرکت).
- بخش‌های دیگر خام‌اند؛ از تب «بندهای ممیزی» می‌توان بندها را دستی یا از اکسل وارد کرد.
- نمره شرکت = مجموع (نتیجه ارزیابی × نمره بند) همه بندها.
- گزارش PDF: دکمه «گزارش PDF» ← در پنجره چاپ، مقصد «Save as PDF».

## اجرا روی رایانه
هیچ ابزار ساختی لازم نیست:

    python3 -m http.server 8000     # سپس http://localhost:8000

## استقرار
1. پوشه را در یک مخزن GitHub بگذارید (`git init && git add . && git commit -m init && git push`).
2. در Vercel: Add New ← Project ← انتخاب مخزن ← Framework Preset: **Other** ← Deploy (بدون Build Command).
3. (اختیاری) GitHub Pages هم کار می‌کند: Settings ← Pages ← Deploy from branch ← `/ (root)`.

## ذخیره‌سازی داده
داده‌ها در localStorage مرورگر ذخیره می‌شوند. برای انتقال بین رایانه‌ها/کاربران از صفحه «داده‌ها»
فایل پشتیبان (JSON) بگیرید و بازیابی کنید. برای ثبت هم‌زمان چندکاربره باید بک‌اند (مثل Supabase) با ورود کاربران و نقش‌ها اضافه شود.

## ساختار
    index.html        صفحه اصلی
    css/style.css     استایل و چاپ
    js/seed.js        شرکت‌ها و بندها/نمرات اولیه محیط زیست ۱۴۰۴
    js/core.js        وضعیت، محاسبه، نمودارها
    js/views.js       صفحات و گزارش
    fonts/            فونت وزیرمتن

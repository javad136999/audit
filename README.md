# پایش‌بان — سامانهٔ ممیزی سالانهٔ پتروشیمی‌های عسلویه

داشبورد فارسی و راست‌به‌چپ برای ثبت، پایش و گزارش ممیزی شرکت‌های پتروشیمی در پنج حوزهٔ محیط‌زیست، بهداشت، ایمنی، مدیریت بحران و آتش‌نشانی.

## وضعیت نسخه

- **محیط‌زیست:** چک‌لیست بندبه‌بند از شیت مبنا وارد شده است. برای ۱۲ شرکت که ریزنمره در فایل داشتند، پاسخ هر بند پیش‌بارگذاری شده؛ نمرهٔ محاسباتی هرکدام با نمرهٔ نهایی شیت کنترل و برابر است.
- **فهرست شرکت‌ها:** هر ۳۱ نام از شیت اول آمده است. نمره‌های کل سال‌های ۱۴۰۳ و ۱۴۰۴ در شیت مبنا حفظ شده‌اند. برای شرکت‌هایی که ریزنمره نداشتند، فقط نمرهٔ کل ثبت‌شده نمایش داده می‌شود و وضعیت آن با «فقط نمرهٔ کل اکسل» مشخص است.
- **بهداشت، ایمنی، مدیریت بحران و آتش‌نشانی:** بدون بند یا امتیاز اولیه؛ کاربر می‌تواند بندهای اختصاصی هر حوزه را اضافه کند.
- **مدیریت بندها:** در هر بخش امکان افزودن بند جدید، ویرایش متن/دسته/وزن پایه و حذف بند با تأیید وجود دارد. بندهای محیط‌زیست از صفحهٔ ممیزی و صفحهٔ «مدیریت بندها» قابل مدیریت‌اند؛ سایر بخش‌ها نیز کنترل‌های خود را دارند. حذف، بند را از همان مرورگر و محاسبات خارج می‌کند.
- **فرمول امتیاز:** امتیاز هر بند = «نتیجهٔ ارزیابی × وزن بند» و نمرهٔ کل = مجموع امتیاز بندها. هر دو مقدار در صفحهٔ ممیزی، کنار همان بند قابل ویرایش هستند؛ نتیجه بین ۰ و ۱ است و با تغییر نتیجه یا وزن، امتیاز بند و کل فوراً محاسبه و ذخیره می‌شود.
- **سال‌های ممیزی:** سال جاری هجری‌شمسی و ۱۰ سال پس از آن به‌طور خودکار در فهرست انتخاب سال نمایش داده می‌شوند؛ سال‌های گذشتهٔ موجود نیز حفظ شده‌اند.
- **گزارش:** گزارش هر حوزه شامل نمودار مقایسهٔ شرکت‌ها و جدول امتیازهاست؛ در پنجرهٔ چاپ مرورگر گزینهٔ «ذخیره به‌صورت PDF» را انتخاب کنید.
- **ذخیره‌سازی:** اطلاعات و تغییرات در localStorage همان مرورگر ذخیره می‌شود. نسخهٔ پشتیبان JSON برای جابه‌جایی بین دستگاه‌ها وجود دارد؛ ذخیره‌سازی مشترک چندکاربره در این نسخه پیاده نشده است.

## اجرا

سایت استاتیک است و نیاز به build ندارد. در ریشهٔ مخزن:

```bash
python3 -m http.server 8000
```

سپس `http://localhost:8000` را باز کنید.

## استقرار روی Vercel

مخزن GitHub را در Vercel وارد کنید و تنظیمات زیر را انتخاب کنید:

- Framework Preset: **Other**
- Build Command: خالی (یا `true`)
- Output Directory: `.`
- Install Command: خالی

سپس Deploy را بزنید. با pushهای بعدی به شاخهٔ متصل‌شده، Vercel استقرار جدید می‌سازد.

## ساختار

```text
index.html      پوستهٔ برنامه
css/style.css   طراحی واکنش‌گرا و استایل چاپ/PDF
js/seed.js      فهرست شرکت‌ها و دادهٔ اولیهٔ ممیزی ۱۴۰۴
js/app.js       داشبورد، ثبت نمره، محاسبه، گزارش و پشتیبان‌گیری
vercel.json     هدرهای پایه برای استقرار استاتیک
```
